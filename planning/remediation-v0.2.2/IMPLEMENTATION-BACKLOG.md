## 2. Stage G1 (Safety Kernel) — Detailed Implementation & Isolation Plan (For Owner Approval)

Stage **G1** covers **`B02` + `B03` + `B04` + `B05` + `B06`** and closes **every confirmed P0 security & data-destruction blocker (`IR-01` through `IR-07` + partial `IR-08` & `IR-12`)** *before* enabling live application launching or file opening in G2.

### 2.1 Isolation & Safety Guarantees During G1
- **Zero Touch on Real Owner Folders:** All G1 negative security tests run strictly inside ephemeral `pytest` `tmp_path` directories (`<TEMP>\pytest-*`), never targeting `%USERPROFILE%\Documents`, `Desktop`, `Downloads`, or live user databases.
- **No Unapproved Side Effects:** Zero new model downloads, zero OS/registry mutations, zero global tool installs, zero network egress, zero `git push`.
- **Reversible Surgical Patches:** Every modified module preserves existing public APIs/schemas where sound; dangerous endpoints (`POST /v1/storage/migrate`, remote gateway, unhardened web fetch, unverified extension exec) fail closed behind explicit safety gates until their hardened vertical slices pass.

### 2.2 Exact G1 Patch Scope (5 Cohesive Slices)
1. **Slice G1.1 (`B02` — Single Policy Gateway & Grant Integrity):**
   - Enforce `grant.scope` canonical path containment inside `core/jarvis/domain/policy.py:_has_active_grant`.
   - Add unique active grant deduplication + atomic cascade revoke in SQLite (`core/jarvis/transport/app.py` & `core/jarvis/application/`).
   - Remove silent `screen.read` auto-grant from `apps/desktop/src/lib/brokerClient.ts:273-278`.
   - Route sensitive REST endpoints (`/v1/storage/*`, `/v1/backups/*`, `/v1/screen/analyze`, `/v1/web/*`, `/v1/iot/ha/actuate`, `/v1/workflows/*/execute`, `/v1/camera/*`) through one mandatory `AuthorizedActionGateway`.
2. **Slice G1.2 (`B03` — Ownership-Bound Cache, No-Delete & No-Clobber Guards):**
   - Add shared `SafePathBoundary` (canonical `realpath`, reparse-point/junction rejection, immutable system/secret directory exclusions).
   - Harden `storage_service.py`: `set_location("cache", ...)` rejects non-empty user dirs & requires owned `.jarvis-cache-owned` sentinel; `cleanup_cache_lru` checks sentinel + skips reparse points + never deletes user data.
   - Harden `backup_service.py`: confine archive writes strictly to managed backup root using create-new (`O_EXCL` / no-clobber) semantics so existing files can never be overwritten.
   - Disable unhardened `/v1/storage/migrate` and remote gateway routes with explicit `503 CAPABILITY_DISABLED_PENDING_HARDENING` until G5/G7.
3. **Slice G1.3 (`B04` — Cryptographic GUI Approval & Workflow Bypass Closure):**
   - Require a single-use, unconsumed `ApprovalService` GUI nonce bound to `bound_hash` inside `workflow_service.py:execute_workflow` (closing self-echo bypass).
   - Enforce `target_snapshot_hash` verification, expiry, and atomic single-use consumption; reject voice-only approvals with authoritative channel binding (not trusting raw JSON `modality`/`origin` alone).
   - Reject mock workflow execution in production (`workflow_service.py:351-359` returns explicit `501/UNSUPPORTED` until real executor lands in G4).
4. **Slice G1.4 (`B05` — Transport, Rust IPC, OS Lock, SSRF & Logging Hardening):**
   - Validate & percent-encode all 8 path-interpolated IDs in `apps/desktop/src-tauri/src/commands.rs` (reject `/`, `\`, `..`, `%2f`).
   - Fix `app.py` IPv6 `[::1]` Host parsing, empty Host rejection, chunked-transfer 256 KiB cap, and `ErrorEnvelope` on HTTP 422.
   - Replace hardcoded `is_os_locked=False` with real Windows workstation lock probe (`OpenInputDesktop` / `WTSQuerySessionInformation`) + persistent server-side lock state in `/v1/session/lock`.
   - Disable/harden `web_fetch.py`: pin socket connection to validated `pinned_ip` with SNI preserved + stream-cap bytes at `2 MiB` before buffering.
   - Reorder `logging_setup.py` so redaction executes **after** `format_exc_info` and catches `recovery_passphrase`, `bearer_token`, `pairing_code`; bound `crypto.py` Argon2id header parameters.
5. **Slice G1.5 (`B06` — Provenance Verification & Production Fake-Adapter Ban):**
   - Enforce SHA-256 verification against a trusted local manifest before spawning `llama-server.exe` or loading model/voice files (fail closed with clear diagnostic error on mismatch/untrusted binary).
   - Ban silent fake-success defaults in `app.py` composition root (`FakeNotificationAdapter` marked `unavailable` rather than claiming delivery; `allow_live_launch=False` returns explicit `UNAVAILABLE` instead of fake `verified=True` until G2 `B09` enables verified native catalog launch).

### 2.3 Stage G1 Exit Gate
- Full regression pass on existing `pytest`, `Vitest`, and `cargo test` suites (updating any tests that relied on fake `verified=True` or self-echo bypasses to assert truthful hardened behavior).
- Brand-new **G1 Negative Security Suite (`tests/security/test_g1_safety_kernel.py`)** covering all 14 negative scenarios from Review §5.3 (`0` unauthorized side effects, `0` user-file deletions, `0` bypasses across all entrypoints).
- Updated evidence record & traceability mapping presented to Monarch at **Gate G1** before proceeding to **Stage G2**.
